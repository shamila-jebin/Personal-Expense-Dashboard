# Personal-Expense-Dashboard
Personal Expense Dashboard created using Microsoft Excel to analyze income, expenses, spending categories, accounts, and financial trends.
 💰 Personal Expense Dashboard – Excel

 📌 Project Overview

This project is a Personal Expense Analysis Dashboard created using Microsoft Excel.

The dashboard analyzes personal financial transactions to provide an overview of income, expenses, spending categories, account-wise spending, and financial trends.

 📊 Dashboard Features

- Key Financial Metrics
- Total Spend by Account
- Expenses by Category
- Income vs Expenses
- Category-wise Expense Analysis
- Account-wise Spending Analysis
- Transaction Analysis
- Interactive Excel Dashboard

🗂️ Dataset

The dataset contains 563 financial transaction records with the following fields:

- Account
- Date
- Description
- Debit
- Credit
- Amount
- Sub-category
- Category
- Category Type

 🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Analysis
- Data Visualization

🎯 Project Objective

The objective of this project is to transform personal financial transaction data into an interactive Excel dashboard that helps analyze income, expenses, spending patterns, account-wise spending, and expense categories.

📈 Analysis Included

The dashboard provides analysis of:

- Total spending by account
- Expenses by category
- Income vs expenses
- Spending across different categories
- Income and expense transactions
- Financial transaction trends
